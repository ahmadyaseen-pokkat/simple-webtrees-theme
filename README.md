# EasyTree

![Development Status](https://img.shields.io/badge/status-in%20development-yellow)

EasyTree (aka `beginner_friendly_theme`) is a streamlined webtrees theme focused on 
simplicity for beginners. Built by modifying the [JustLight theme](https://github.com/JustCarmen/webtrees-theme-justlight) 
via CSS removal with assistance from Claude AI, the goal is to strip down features 
that overwhelm new users and provide a cleaner, more approachable experience.

## About the Name

I originally called this theme "SimplyLight," a nod to the underlying 
[JustLight theme](https://github.com/JustCarmen/webtrees-theme-justlight) by 
[JustCarmen](https://github.com/JustCarmen) it is built upon — but the name caused 
confusion, as it sounded too similar to the built-in "Light" theme, and I even 
assumed there was no dark theme available until I explored further. By including 
"Tree" in the name, beginners can easily connect it to webtrees, and the "Easy" 
makes it clear this theme is made with them in mind.
